Ayuda — Aplicación Control de Acceso

Esta aplicación permite gestionar la entrada y salida de usuarios en el gimnasio y consultar su historial de accesos.

1. Selector de Usuario (ComboBox)

El desplegable de usuarios permite seleccionar la persona sobre la que se realizará una acción.

  • Muestra todos los usuarios registrados.
  • Debe seleccionarse un usuario antes de pulsar cualquier botón.
  • Activa automáticamente los botones disponibles.

2. Botón "Entra"

Registra la entrada del usuario seleccionado al gimnasio.

  • Añade al usuario a la lista de personas dentro.
  • Guarda el movimiento en la base de datos.
  • Actualiza el historial automáticamente.

3. Botón "Sale"

Registra la salida del usuario del gimnasio.

  • Elimina al usuario de la lista de personas dentro.
  • Registra una salida en la base de datos.
  • Actualiza el historial mostrado.

4. Panel de Historial

El historial muestra todos los movimientos realizados durante la sesión.

  • Se añaden automáticamente entradas y salidas.
  • Puede limpiarse usando el botón "Limpiar historial".
  • Permite generar informes en PDF.

Consejo: Pulse la tecla F1 en cualquier momento para abrir esta ayuda.
